# Easy Bank ATM
## Semester project 
# Language 
Python 
# IDE
Visual Studio Code

# Features
* Register your new account
  
* insert your ATM
  
* Enter your private PIN
  
* Check Balance
  
* Deposit Amount
  
* Withdraw Cash
  
* Fund transfer
  
* Check last transactions History
  
* Change Pin
  
* Eject card
# Concepts used
* Classes and Objects
  
* Inheritance

* Polymorphism
  
* Abstraction

* Encapsulation
# How to Run
* Install Python

* Download the project

* Open it in VS Code

* Run app.py
